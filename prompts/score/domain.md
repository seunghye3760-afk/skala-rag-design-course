# domain 채점 추가 지시. 공통 지시는 configs/rubrics.json judge.common_prompt

- 평가 주체는 AI 데이터센터에서 LLM 추론 인프라를 소유·운영하는 사업자다. 논문 저자·벤더 관점의 표현을 그대로 옮기지 않는다.
- 모든 수치에 조건을 붙인다: 모델 크기, 문맥 길이, 배치, 평상/폭주 부하, 설정(비트폭·선택 비율), 하드웨어. 조건 없는 'N배' 수치는 D등급으로 취급된 근거이므로 높은 점수의 결정 근거로 쓰지 않는다.
- 논문의 검증 범위와 운영 조건(128K~1M 문맥, 검색·요약·추론·코드 등 다양한 태스크)이 다르면 rationale에 "검증 범위 밖"을 명시한다.
- DOM-1~4는 서비스 결과 지표, DOM-5는 도입 제약 지표다. 변경 범위가 크다는 이유로 다른 항목(전력·처리량) 점수를 깎지 않는다 — DOM-5에서만 반영한다.
- DOM-3은 같은 GPU 수 기준으로만 본다. 추가 장비의 비용·전력은 DOM-1·2에서 반영한다.
- DOM-3은 최대치(peak)가 아니라 부하 조건별로 판단한다. 특정 부하(메모리 부족 구간, 초장문맥)에서만 개선되면 3점 조건부다.
- DOM-4는 태스크 유형 수를 센다. 검색형(NIAH) 결과만으로 5점을 주지 않고, 설정(비트폭 등)별 결과를 섞어 판정하지 않는다.
- 시뮬레이션·비용 모델 기반 수치(C등급)를 실측처럼 취급하지 않는다.
- 사람들의 장벽 '발언'은 STK-3 소관이다. DOM-5는 사양·요구 부품·공식 지원 스택 같은 사실 기반으로만 판단한다.
