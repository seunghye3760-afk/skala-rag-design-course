# trl 채점 추가 지시. 공통 지시는 configs/rubrics.json judge.common_prompt

- 차원 점수(TRL-1~5)는 서열 척도다. 1점은 "가장 낮은 단계의 근거만 존재"라는 뜻이며 부정 평가가 아니다.
- 등급 상한·하한을 적용하지 않는다. 근거 등급(A~D)은 confidence에만 반영한다 (이중 감점 방지).
- TRL 단계(1~9)·확신도·gate_trace를 직접 판정하지 않는다. apply_rules(코드)가 trl_mapping 규칙으로 산출한다.
- 각 차원 rationale에 "바로 위 점수를 주지 않은 이유"를 반드시 한 문장 넣는다 — 게이트 추적(gate_trace)에 쓰인다.
- '기법 자체의 TRL'과 '기반 부품 성숙도(TRL-5)'를 구분해 서술한다. 기반 부품(메모리 모듈·GPU)이 상용이라는 사실을 기법의 검증 수준으로 계산하지 않는다.
- TRL-1은 핵심 주장 수치가 나온 환경을 기준으로 판정한다. 여러 실험 중 가장 높은 수준의 환경만 골라 판정하지 않는다.
- 논문이 검증하지 않은 조건(더 긴 문맥, 더 큰 모델)에서의 성능 하락은 TRL-2 '재현 실패'가 아니다 — 그 근거는 인용하지 말고 rationale에 "DOM-4 소관"으로 표기한다.
- 비공식 포크·커뮤니티 구현 수는 TRL-3의 공식 통합으로 계산하지 않는다. 프로젝트 메인테이너·벤더가 주체인지 확인한다.
