## F. 판단이 필요한 열린 질문 (팀에서 정할 것)

- 동적 fan-out의 "동적" 근거를 무엇으로 둘지: (a) `tech_briefs` 기반으로 셀별 검색 채널 선택, (b) 이전 라운드 결과로 불필요 셀 제외, (c) 둘 다. → (c) 권장.
- Judge 임계값(예 4/5)과 미달 시 재생성 횟수(2회) — 비용 vs 재현성.
- `plan_tasks`를 LLM으로 할지 규칙으로 할지. 재현성 채점(10점)을 고려하면 **규칙 + LLM 보조(채널 선택만)** 권장.
